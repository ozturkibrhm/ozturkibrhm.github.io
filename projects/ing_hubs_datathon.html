ING Hubs Turkey Datathon: Predictive Banking Churn Architecture (Top 10 Finalist)

  • Tech Stack: Python, AutoGluon, CatBoost, LightGBM, XGBoost, Scikit-Learn, Optuna, Pandas, NumPy, Kaggle Notebooks
  • Project URL: Project Link

This project was developed for the official ING Hubs Turkey Datathon, where our team designed an end-to-end predictive machine learning architecture to identify customer churn patterns in banking, securing a Top 10 Finalist position among numerous highly competitive data science teams.

Data Pipeline

  • Data Alignment & Category Handling: Cleaned and aligned categorical features across high-dimensional banking tracking logs, implementing automated frequency thresholding to collapse rare categories into a consolidated bin.
  • Correlation-Based Feature Selection: Designed automated feature pruning routines to dynamically drop highly collinear numerical variables (Pearson threshold > 0.99) to optimize model memory footprint and training speed.
  • Data Quality & Validation: Managed continuous data validation steps, handling missing values, duplicates, and extreme outliers safely without losing predictive customer signal.

Modeling & Ensemble Architecture

  • Multi-Layer Stacking: Leveraged a state-of-the-art stacking architecture with multiple model levels (L1 to L3) utilizing an advanced bagged ensemble framework.
  • Heterogeneous Model Blend: Systematically combined optimized variants of LightGBM (with Extra Trees variations), CatBoost, XGBoost, Random Forests, and Deep Learning (NeuralNetTorch) to stabilize prediction probabilities.
  • Probability Calibration: Applied Temperature Scaling grid-search calibration on out-of-fold (OOF) validation logits to ensure predicted churn probabilities perfectly aligned with real-world distribution.
  • Competition Metrics: Evaluated performance metrics based on Gini, Recall@10%, and Lift@10% to achieve highly generalizable validation scores.

The final solution produced reliable, stable probability distributions and generated a Kaggle-ready submission.csv with calibrated customer churn test predictions.
